# Getting help

Start with the [README](README.md), [getting-started guide](docs/start-here.md),
[Mac guide](docs/mac.md), and [testing guide](docs/TESTING.md).

- For a reproducible bug, use the [bug report template](https://github.com/ChaseHendrick/Scrolls/issues/new?template=bug_report.md).
- For an improvement or documentation change, use the [feature request template](https://github.com/ChaseHendrick/Scrolls/issues/new?template=feature_request.md).
- For a usage question, use the [question template](https://github.com/ChaseHendrick/Scrolls/issues/new?template=question.md).
- For vulnerabilities, follow the [private security reporting policy](SECURITY.md).
- For conduct concerns, follow the [code of conduct](CODE_OF_CONDUCT.md).

Search existing issues first. Include your command, commit hash, Python version,
operating system, expected behavior and a small sanitized example where relevant.
Please do not attach raw datasets, weights, credentials, candidate images,
private results or personal information. Use synthetic fixtures or links to
already-public sources instead.

This repository provides an independent workbench around the official tools.
For upstream engine bugs, consult [ScrollPrize/villa](https://github.com/ScrollPrize/villa).
For official prize rules and submission questions, consult
[the Vesuvius Challenge](https://scrollprize.org/). Maintainer responses do not
represent prize organizers or establish eligibility. Support is best effort.
