# Repository map

One row per module, script folder and docs area. [AGENTS.md](../AGENTS.md) holds the rules and points here; search this table (`grep -n "auc" docs/MAP.md`) instead of reading it whole. `tests/test_repo.py` checks that every `kit/*.py` module has a row. Add a row when you add a module or a script folder.

| Path | What it is |
| --- | --- |
| `kit/` | Standard-library Python package, `python -m kit` (numpy, tifffile, zarr only for map tools) |
| `kit/prizes.py`, `kit/data/prizes-*.json` | Dated prize snapshot: amounts, deadlines, eligible volumes with S3 names and voxel sizes |
| `kit/doctor.py` | Machine check: GPU (CUDA or Apple Silicon), memory, disk, tools |
| `kit/scancatalog.py` | Catalog of every scan volume in the vesuvius-challenge-open-data S3 bucket, with per-scan config |
| `kit/autobatch.py` | Priced dry-run batch over the catalog (`kit run all`) and the new-scan watcher (`kit run watch`); launches nothing |
| `kit/plan.py` | Prints the official First Letters commands for one scroll (never runs them) |
| `kit/cli.py`, `kit/__main__.py` | The `python -m kit` entry point: every subcommand and its help text |
| `kit/fetch.py` | Resumable anonymous download of a bucket prefix; aliases `w035`, `w045` |
| `kit/layers.py` | Surface-volume zarr to numbered layer TIFFs (v8in's input), banded reads, optional crop; `kit shuffle` and `kit layers --shuffle SEED` write the depth-shuffle control |
| `kit/verify.py` | Two maps agree within tolerance, valid only if a control map is caught |
| `kit/auc.py` | Pixel AUC against a segment's `inklabels.zarr` inside `supervision.zarr`; reverse map as control; `--crop`, `--inner` |
| `kit/rowscore.py` | Text-row periodicity triage score (port of Bullo27's); a reading order, not a verdict |
| `kit/provenance.py` | Who ran what, when, on which machine, from which inputs; one digest over the record |
| `kit/ensemble.py` | Average maps of one surface (`python -m kit ensemble OUT MAP MAP ... [--method rank]`); map-level, never cross-seed weights |
| `kit/fibertensor.py` | `kit fibertensor train/predict`: structure-tensor (fibre orientation) features plus a tiny numpy MLP, CPU; a measured null on PHerc0841 and w045 ([log](logs/2026-10-07-grok-laneD.md)) |
| `kit/hpscore.py` | Letter-scale score (Scheirer's 48 um high-pass correlation) against the labels, rolled-key null; pixel AUC rewards blur, this does less |
| `kit/tooldocs.py`, `docs/TOOL-DOCS.md`, `docs/tools/`, `templates/tool-doc.md`, `templates/tool-doc-branch.md` | Tool pages: one page per tool in `docs/tools/ID.md`, written to the standard in `docs/TOOL-DOCS.md` and checked against the code by `python -m kit.tooldocs check` (every option, default, error message, public function and path; every kit module, script, command and release has a page). `index` writes `docs/tools/README.md` and `docs/tools/index.json`; `list`, `show ID` and `new ID` serve agents and writers; `docs/tools/pending.json` lists pages still to be written. Scrolls-private carries an identical copy of the module |
| `kit/releases.py`, `docs/releases.json` | The list of released tools and the README section written from it, pinned entries first and then newest first: `python -m kit releases add ENTRY.json`, `render`, `check`, `list`, `pin ID`, `unpin ID` (rule 15). Scrolls-private's exporter carries an identical copy of the module |
| `kit/routines.py`, `kit/prizewatch.py`, `docs/routines.json`, `.claude/settings.json`, `.github/workflows/routines.yml` | Recurring checks any agent or account runs at session start (`python3 -m kit routines run --due`, `status`, `due`, `list`, `check handoff`): the registry in `docs/routines.json` (daily or weekly by UTC date, timeouts, read-only `python -m kit` commands only, credentials stripped), results in the ignored `work/routines/`; the Claude Code SessionStart hook runs the due ones in the background, and the daily workflow runs the ones marked ci with the test suite (no secrets, read-only token). `kit.prizewatch` compares the live prize page with the dated snapshot; [rulebook](AI-AGENTS.md#session-start-repository-routines) |
| `kit/letterread.py`, `kit/greeklm.py`, `kit/letterexport.py`, `kit/letterlines.py`, `kit/letterdemo.py` | Scroll Text Reader's Greek backend (`python -m kit letterread IMAGE --weights letters-v2-ccby [--letter-px H | --letter-mm MM --um-per-px UM] [--overlay PNG]`): whole maps block-averaged while loading (TIFF, zarr, OME-Zarr), numpy CTC line network, columns and lines, deskew with a limit warning, turned and mirrored reads (`--rotate`, `--mirror`), polarity by a quick read both ways for photographs (`--polarity auto`) and EXIF orientation, null, control-map and orientation controls with a status code per read and per column, overlay drawn the way round the image was given, released weights downloaded once and SHA-256 checked (`kit/data/letter-weights.json`: `letters-v2-ccby`, CC BY 4.0, the automatic-layout default, and `letters-v2-real`, CC BY-NC 4.0), a Python `read()` that takes a model name, path or loaded network and checks its input, a schema number, the weights' SHA-256, the seed and the options in every result (file names only, no local folder), UTF-8 output for pipes and Windows consoles; exports of a read as a CSV of letters and PAGE XML 2019 (`--csv`, `--page-xml`; `letterexport.py`); training lines for fine-tuning from your own transcribed lines (`python -m kit letterlines build RECORDS --out LINES.npz`, with `--dry-run`) and character error on lines kept apart (`letterlines score`; `letterlines.py`); and a Kneser-Ney letter language model (`python -m kit greeklm build`) reported beside the ink-only decode; an offline demo, synthetic Greek capitals in the training data's skeleton hand and a noise image judged under a fixed rule, DEMO PASS or DEMO FAIL (`python -m kit letterdemo`; `letterdemo.py`). Letter hypotheses, not readings ([guide](letter-reader.md)) |
| `kit/letterweights.py`, `kit/reader_backends.py` | Scroll Text Reader profiles and backends: task-aware Greek weights (given ink-map lines select real/CC BY-NC; automatic layout selects ccby/CC BY; explicit weights preserved), and explicit per-call switching to local Tesseract language packs with model hashes, word boxes and controls. No implicit multilingual support from Greek weights or remote inference ([reader backends](tools/reader-backends.md)) |
| `kit/starter.py`, `kit/data/starter.html`, `kit/data/starter.js` | Scrolls Starter (`scrolls-start`, `python -m kit start`): a self-contained local browser introduction, real setup snapshot, teaching-only known-answer control exercise, official workflow next steps and optional Scroll Text Reader command builder. Standard library only; no server, downloads or inference ([tool page](tools/starter.md)) |
| `pyproject.toml`, `CITATION.cff`, `CHANGELOG.md`, `.gitattributes`, `.github/workflows/check.yml` | The installable package `scrolls-workbench` (version in `kit/__init__.py`, what each version holds and how to install a tagged one in `CHANGELOG.md`; `kit` with JSON, HTML and JavaScript in `kit/data/`; extras `reader`, `maps`, `all`; commands `scrolls-workbench`, `scrolls-letterread`, `scrolls-letterlines`, `scrolls-letterdemo`, `scrolls-start`; its own virtual environment, apart from AutoPipeline's, which also installs `kit`), how to cite the repository (Apache-2.0), with each released set of the letter reader's weights as a separate reference under its own licence (`letters-v2-ccby` CC BY 4.0, `letters-v2-real` CC BY-NC 4.0), LF line endings on every system, and CI: the suite with the standard library only and with the map and reader dependencies, and the reader's tests and demo from the installed package on Linux, macOS and Windows ([guide](letter-reader.md#install)) |
| `kit/strokenet.py`, `scripts/strokenet/`, `tests/test_strokenet*.py`, `tests/test_gridpilot.py` | StrokeNet, a text-likeness score for 6.1 mm windows of an organisers' ink map (`python -m kit strokenet MAP --pixel-mm P`): numpy inference with the training window rule (99 % core papyrus), exact pooling of integer maps, a crop snapped to the 32 px training lattice, rotation and IAAFT controls read against validation reference values, released weights downloaded once and SHA-256 checked (`kit/data/strokenet-weights.json`, release `strokenet-paris4-v1`). `scripts/strokenet/` holds the dataset build (`data.py`), nulls and seam-matched windows (`nulls.py`), training (`train.py`, torch), metrics, baselines, evaluation and the preregistered pipeline (`pipeline.py`, `evaluate.py`, `prov.py`), and the tile grid pilot's readout (`gridpilot.py`). Misses its preregistered bar on the held-out test; Model output, not a reading ([model card](strokenet.md), [evidence](evidence/2026-10-14-strokenet/README.md)) |
| `scripts/umbilicus/`, `tests/test_umbilicus.py` | Scroll centre (umbilicus) finder: `predict.py` writes a centre line in the published umbilicus format from a scroll's 1.2 m scan and the released weights (two small U-Nets, torch; release `umbilicus-v1`); `slices.py`, `centrenet.py`, `refine.py` and `pipeline.py` train it and score it against the 13 published centre lines with each scroll held out of its own models, beside a papyrus-centroid control; `endcheck.py` calibrates, scores and applies the end-point rule; `ctcheck.py` draws lines on CT slices for a person to check.
