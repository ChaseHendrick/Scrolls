# Community standards

Short specs that any Vesuvius Challenge team can follow, check a claim against or cite in a submission. Each is a draft until the owner approves it; none is an organizer rule.

| Standard | Status | What it covers |
| --- | --- | --- |
| [Sim Realism Standard (SRS-1)](sim-realism.md) | Draft 1, 26 Nov 2026 | How real a set of simulated scroll CT tiles looks against a fixed real reference (R343-v1 by default): three fresh critics on grouped folds, planted and control gates, the fixed simcritic pass bar, a calibrated sample-size rule and a checkable JSON record; reference scorer [`kit.simscore`](../tools/simscore.md) |
