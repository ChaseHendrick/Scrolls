# Greek gap restoration: frozen files

The frozen files of the Greek gap restoration test of 22 October 2026: hosted text models and a Kneser-Ney letter model restoring hidden letters in Philodemus, De Musica. Rules and result: [`../../prereg/2026-10-22-greek-restoration.md`](../../prereg/2026-10-22-greek-restoration.md). Code: [`kit/greekfill.py`](../../../kit/greekfill.py) and [`kit/greekkn.py`](../../../kit/greekkn.py) ([tool page](../../tools/greekfill.md)). All scores are Model output. Public text only: no scroll data, ink map or finding.

The five data files are copied byte for byte from the run's own folder; never edit them.

`SHA256SUMS` lists the same five (`sha256sum -c SHA256SUMS` here); `python -m kit.greekfill check docs/evidence/greek-restoration-20261022` compares them with the pins in the code.

## Reproduction, 22 October 2026

Checked in a 4-core Claude cloud container (Python 3.13, numpy 2.5.3) with the public code:

- `python -m kit.greekfill score` on these files wrote a `score.json` byte-identical to the one here (1.4 s).
- `python -m kit.greekfill corpus` on clones of PerseusDL/canonical-greekLit at `0189b9c8d8d1f148133f2f0af309b4ee90ea4332` and OpenGreekAndLatin/First1KGreek at `03776b39f4047c5cff06f5296fae4b2bae4b08fb` (in that order, `--nproc 4`) wrote 1,935 documents and 169,474,563 letters with sha256 `5c7c4684b7a4515ebd8840b963757b5a7680cfd2c986375a487b3d66bdb594bf`, the corpus of the run (5 min 26 s).
- `python -m kit.greekfill prep` on that corpus refitted both KN models and wrote `manifest.json`, `key.json` and `baseline.json` byte-identical to the ones here, and printed a KN gap letter accuracy of 0.331 (1 min 57 s).

The hosted-model replies cannot be regenerated byte for byte: a rerun of `run` would ask the providers again.
