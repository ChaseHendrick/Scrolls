# AutoPipeline bars (pointer)

The AutoPipeline bars plan of 9 October 2026 fixes the metric and the pass bar of each AutoPipeline stage. It lives in [Scrolls-private](https://github.com/ChaseHendrick/Scrolls-private) (access required).

The AutoPipeline release packages (public branches `submission/progress-2026-10-fix5` and later) cite the plan by this path: their tracing score, `kit surfbench gscore`, implements its stage 2 metric, and their surface prediction score its stage 4 metric. The frozen tracing rule names the plan, so the path stays as it is. The released code and its tests are the public statement of each metric. AutoPipeline's guide is [`docs/autopipeline/README.md`](../autopipeline/README.md).
