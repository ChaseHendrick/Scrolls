# Connect your tool: Scroll Lens

The twelve scans Scroll Lens reads are open data, and each one reads straight from its URL in your own tool. The page itself is also an API and an MCP server.

Checked 2026-10-24. Generated by `python -m kit spaceconnect render` from `connect.json`.

## A scan it reads, example PHerc0139 2.399 um

`https://vesuvius-challenge-open-data.s3.us-east-1.amazonaws.com/PHerc0139/volumes/20260102150214-2.399um-0.2m-78keV-masked.zarr`

License: CC BY-NC 4.0 (Vesuvius Challenge open data). The other eleven are listed by list_scans; all are read live, never copied here. Scroll Lens reads level 0.

### Python (zarr) (tested 2026-10-24)

```python
# pip install "zarr>=3" fsspec aiohttp
import zarr

root = zarr.open_group("https://vesuvius-challenge-open-data.s3.us-east-1.amazonaws.com/PHerc0139/volumes/20260102150214-2.399um-0.2m-78keV-masked.zarr", mode="r")  # OME-Zarr, zarr v2
a = root["3"]  # level 0 is full resolution; level L is 2**L times coarser
print(a.shape, a.dtype, a.chunks)
block = a[4810:4874, 1657:1721, 1657:1721]  # (z, y, x); reads only the chunks it touches
```

## Call Scroll Lens from code or an agent

`https://huggingface.co/spaces/SharpMeow/scroll-lens`

License: Code Apache 2.0; models as listed by list_scans; scans CC BY-NC 4.0. The Space is paused, so these calls wait until it runs again. A new point uses the caller's ZeroGPU minutes. Model output, not a reading.

### Python /list_gallery (Space paused)

```python
# pip install gradio_client
from gradio_client import Client

client = Client("SharpMeow/scroll-lens")
result = client.predict(api_name="/list_gallery")
```

### Python /list_scans (Space paused)

```python
# pip install gradio_client
from gradio_client import Client

client = Client("SharpMeow/scroll-lens")
result = client.predict(api_name="/list_scans")
```

### Python /random_point (Space paused)

```python
# pip install gradio_client
from gradio_client import Client

client = Client("SharpMeow/scroll-lens")
result = client.predict(scan="PHerc0139", seed=0, api_name="/random_point")
```

### curl /list_gallery (Space paused)

```bash
URL=https://sharpmeow-scroll-lens.hf.space
EVENT=$(curl -s -X POST $URL/gradio_api/call/list_gallery -H 'Content-Type: application/json' \
  -d '{"data": []}' | python3 -c 'import json,sys; print(json.load(sys.stdin)["event_id"])')
curl -sN $URL/gradio_api/call/list_gallery/$EVENT
```
