From Python

Standard library only, no key.

import json, urllib.parse, urllib.request

BASE = "https://sharpmeow-vesuvius-radar.hf.space"

def get(path, **params):
    url = BASE + path + "?" + urllib.parse.urlencode(params)
    return json.load(urllib.request.urlopen(url))

week = get("/api/items", since="7d", view="builders", min_score=35, limit=100)
for i in week["items"]:
    print(i["score"], i["source"], i["title"], i["url"])

# rank the last month by meaning
hits = get("/api/items", since="30d", q="tracing papyrus fibers", by_meaning="true")

What it is for

  • Researchers see new papers and methods in the areas the scrolls need: sheet and surface segmentation, ink detection in X-ray CT, fiber tracing, registration, compression of huge volumes, 3D encoders and reading damaged Greek and Latin text.
  • The Challenge team sees what the community shipped and said about the scrolls: villa pull requests, issues and releases, new repositories, Hugging Face uploads, Zenodo records and blog posts.
  • Contributors and competitors see what they can use today: repositories, releases, models, datasets, Spaces, package versions and papers that link their code.

What the collector reads

Only public pages and APIs, logged out, on a schedule per source (the Sources tab shows when each last ran). It keeps 30 days, so changing the lookback is instant.

    Anyone can press Check now; to stay polite to these services there is one check at a time for the whole Space and a few minutes between checks. Chat servers and social media are not read. When the Space has been asleep it catches up on the time it missed at the next check.

    How an item is scored

    Every item gets two scores from 0 to 100, and the page shows both.

    Keywords. Scroll terms (Vesuvius, Herculaneum, PHerc, papyrus, Volume Cartographer and similar) add the most. In each topic a strong term counts on its own and a weak term counts half, and only when a context term such as 3D, CT or volume is present too. Terms like LLM or chatbot take points off. Each item lists every term group and its points.

    Meaning. A small sentence-embedding model (BAAI/bge-small-en-v1.5, run on the Space's CPU) compares the item's title and the start of its summary (600 characters) with a set of sentences that describe the work the scrolls need, and reports the closest one. That catches items that never use our words. After the Space restarts, its first check reads every listing by meaning again, which takes several minutes on a small CPU; the Sources tab shows its progress, and items already stored stay on the page meanwhile.

    Final score. The higher of the keyword score and a blend of both, so meaning alone can lift an item to the medium band but only keywords and meaning together reach high (60 or more). A long text that the model reads as unrelated (cosine under 0.70, such as keyword stuffing or a language it does not read) stays below high, unless it comes from ScrollPrize/villa. The same model powers search by meaning and "More like this".
