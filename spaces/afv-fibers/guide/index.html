Every horizontal and vertical papyrus fiber that Qual's AFV V2 model finds in six whole Herculaneum scans, traced into curves: 23,201,743 fibers, 3,806,584 of them 1 mm or longer.

Made and shared by Chase Hendrick, October 2026. Model, spline generator and .afv format by Qual, Apache 2.0.

How it was made

  1. Fiber maps from Qual's AFV V2 model on Hugging Face Jobs, his recipe exactly: 128-voxel windows at stride 64 on one global lattice, Gaussian blending, bf16, on RTX PRO 6000 GPUs.
  2. Curves from his AVF_SPLINE_GENERATOR, one 1024-voxel region at a time with a 128-voxel halo, on CPU Jobs.
  3. Stitching the regions into one file per scan, joining curves where their ends meet across region faces, then Qual's CT exterior cleaning.
  4. Checks: on a test cube of Qual's own published V2 set the pipeline matches his fibers to 98% within one voxel, lengths within 1%; stitched regions match one unsplit run to 99.75 to 99.99%; every published file passes villa's own AFV reader.

The six scans used the plain model. For the next ones, compiling it (PyTorch max-autotune, with the compiled kernels cached between Jobs) runs 1.47 times faster on the same GPU and gives the same fibers.

Measured end to end on Hugging Face Jobs, 27 October 2026.

Bigger windows and wider strides are faster but move 4 to 8% of the fibers, so they stay off; the compiled model changes 0.2%, the same as running the plain model twice. Test cube: 640 voxels of PHerc0125.

Use them

  • Explore a box tab: the CT with fibers, a 3D view, and the box as its own .afv.
  • Python: an .afv is a read-only SQLite file; every dataset has load_example.py.
  • VC3D: villa's import_afv.py turns any file here into a fiber object store.
  • Agents: the page is an API and an MCP server (Agents and API tab).

Fibers are model output about papyrus structure: geometry, not a reading of any text. Scans: Vesuvius Challenge open data, CC BY-NC 4.0; the fiber files are derived from them under the same terms.
