# Connect your tool: Crackle Check

Crackle Check runs from your own code and agents as well as this page, and the segments it reads are open data you can load yourself, with no account needed for either.

Checked 2026-10-24. Generated by `python -m kit spaceconnect render` from `connect.json`.

## Call Crackle Check from code or an agent

`https://huggingface.co/spaces/SharpMeow/crackle-check`

License: Code Apache 2.0; readers MIT; scans CC BY-NC 4.0. Examples are precomputed; a new region uses ZeroGPU time, so pass Client(..., token=...) to use your own. Model output, not a reading.

### Python /check_example (tested 2026-10-24)

```python
# pip install gradio_client
from gradio_client import Client

client = Client("SharpMeow/crackle-check")
result = client.predict(sample_id="0841-w00", reader="readerv3", api_name="/check_example")
```

### curl /check_example (tested 2026-10-24)

```bash
URL=https://sharpmeow-crackle-check.hf.space
EVENT=$(curl -s -X POST $URL/gradio_api/call/check_example -H 'Content-Type: application/json' \
  -d '{"data": ["0841-w00", "readerv3"]}' | python3 -c 'import json,sys; print(json.load(sys.stdin)["event_id"])')
curl -sN $URL/gradio_api/call/check_example/$EVENT
```

## The layers it reads, example PHerc0841 w00 (9.366 um surface volume)

`https://vesuvius-challenge-open-data.s3.us-east-1.amazonaws.com/PHerc0841/segments/20260220213127-w00/surface-volumes/9.366um-1.2m-113keV-volume-20250821151531.zarr`

License: CC BY-NC 4.0 (Vesuvius Challenge open data). Shape (layers, height, width). Read live from the open data when someone runs a check; nothing is bundled.

### Python (zarr) (tested 2026-10-24)

```python
# pip install "zarr>=3" fsspec aiohttp
import zarr

root = zarr.open_group("https://vesuvius-challenge-open-data.s3.us-east-1.amazonaws.com/PHerc0841/segments/20260220213127-w00/surface-volumes/9.366um-1.2m-113keV-volume-20250821151531.zarr", mode="r")  # OME-Zarr, zarr v2
a = root["0"]  # level 0 is full resolution; level L is 2**L times coarser
print(a.shape, a.dtype, a.chunks)
block = a[0:64, 2800:2864, 2900:2964]  # (z, y, x); reads only the chunks it touches
```

### villa's vesuvius package (tested 2026-10-24)

```python

```
