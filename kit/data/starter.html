Try a check that can fail

Teaching exercise only. These pixels draw the known word INK. There is no scan, trained model or text recognition here.

Green marks pixels above your threshold. Keep the drawn strokes while rejecting the noise-only control. The same threshold applies to both images.

What makes this practice pass?

The rule is fixed: at least 90% of kept pixels belong to the strokes, at least 80% of the drawn strokes survive, and the control keeps no more than 10% of the number of drawn ink pixels. Try threshold 0 or 100, or contaminate the control: a pass must be able to turn into a fail.

Real ink maps need independent controls and data kept apart for evaluation. This exercise teaches the idea; its threshold is not a setting for real scrolls.

Ready for the next step: explain why a convincing-looking patch can still fail its control.

Keep your first task small. You do not need to download an entire scroll or train a model to get started.

Understand the data

Open one CT example

Start at the official data page and its Get to know a dataset notebook. Use CPU, inspect the terms before accepting them, then inspect metadata and the existing 256-cubed PHerc0009B example crop. Stop after the three slice views; do not use Run all.

Expected outcome: an image you can describe, not an ink result.

Follow a sheet

Begin with VC3D

Follow the official VC3D setup. Use File > Open Data Catalog and navigate the example volume's planes. Stop before growth; tracing comes after you can follow a sheet through adjacent slices.

Expected outcome: a volume open in VC3D, with one sheet identified across adjacent slices.

Later: automate a workflow with AutoPipeline

AutoPipeline is an existing community tool that coordinates the scan-to-surface-to-ink workflow. First understand the individual official steps, then use its synthetic demo and controls before a real run.

Open the AutoPipeline guide. Its released package needs its own virtual environment, separate from Scrolls Starter, because both packages install a module named kit. Real runs can download large inputs and need external compute.

    Optional community tool · after you have an image
    Prepare a Scroll Text Reader command
    This tool proposes letters or words from an existing image. It does not unwrap a scan, replace the official ink pipeline, or verify a transcription. Start with a small published or personal practice image.
    

    Try the existing reader demo first
    The released demo runs the actual Greek reader on known synthetic letters and on a noise image. It reports DEMO PASS or DEMO FAIL; a pass verifies that example, not scroll accuracy.
    Run it from your scrolls-learning folder after installing the reader's image packages. It uses the terminal choice below and the same .venv paths as Start Here. It may download about 6 MB of CC BY 4.0 weights once. It runs locally on CPU. Read the demo instructions.
    

    1. Choose your input and reader
    Paste a local PNG, JPEG, TIFF or numpy image path. This page does not open or upload it.
    Examples: grc = Ancient Greek, lat = Latin, eng = English. Only installed packs work; no language is guessed.
    For an ink map, use its reverse-depth map on the same grid. Built-in synthetic controls remain enabled.
    

    2. Set scale and outputs
    The ink-line model's comparison used given line positions. Neither choice is established as best for every whole image.
    Measure in the image you will read. Do not copy a size from another scan.
    Use the rendered image's resolution, which may differ from the scan's voxel size.
    Image row numbers, separated by spaces. Leave empty to find lines automatically.
    Use an existing folder and a name not already in use. The reader writes a JSON result and the optional files below.
    PowerShell quoting is not Command Prompt quoting. Installed edition: the Python that generated the page. Portable edition: .venv in your scrolls-learning folder, as in Start Here.
    

    3. Review and run it yourself
    Open the JSON result and inspect its controls. A weak or failed control is a reason to stop and investigate, not to present the text as a reading. Continue with the reader guide.
